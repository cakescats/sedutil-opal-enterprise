# sedutil OPAL Enterprise: SSO-разблокировка и развёртывание через MDM

Корпоративное дополнение к [CakesCats PBA](https://github.com/cakescats/sedutil-pba).
Это поддерживаемый предзагрузочный образ **sedutil** для самошифрующихся SSD
с **TCG OPAL 2.0**. Диски шифруют сами, поэтому производительность не
страдает и лицензии не нужны. Этот репозиторий добавляет то, что нужно
компании.

**Разблокировка корпоративным аккаунтом (SSO).**

- На экране PBA по F2 появляется QR-код.
- Сотрудник сканирует его телефоном и входит через Entra ID, Okta, Google
  Workspace, Keycloak или любой OpenID Connect.
- Сервер разблокировки показывает пароль, который нужно ввести.

Звонить в поддержку не нужно, PBA не нужна сеть, каждая разблокировка
попадает в журнал.

**Развёртывание через MDM.** Подходят Intune, Ansible или любая система,
которая запускает скрипты от SYSTEM или root. Скрипт:

1. регистрирует машину;
2. получает с сервера её образ PBA;
3. включает блокировку.

Повторный запуск безопасен.

**Сервер разблокировки.**

- Небольшое приложение на Flask с SQLite.
- Владельцы задаются для каждой машины, QR-коды одноразовые.
- Есть ограничение на неверные коды и журнал аудита.
- Docker и демо с Keycloak поднимаются одной командой.

## С чего начать

- **[docs/quickstart.ru.md](docs/quickstart.ru.md) — пошагово: сервер, адрес, образ, диск, проверка.**
- [docs/server.md](docs/server.md) — запуск сервера и подключение SSO-провайдера.
- [docs/mdm.md](docs/mdm.md) — развёртывание через Intune, Ansible и другие системы.
- [Документация CakesCats PBA](https://github.com/cakescats/sedutil-pba/tree/main/docs) —
  сам PBA, билдер образов и устройство QR-кода (`sso.md`).

Демо за две минуты:

```
cd server && docker compose up -d --build
```

Откройте http://localhost:8000. Пользователи Keycloak: `alice` / `alice` и
`bob` / `bob`, токен регистрации — `demo-enroll-token`.

| Часть | Состояние |
|---|---|
| Разблокировка по QR-коду через OpenID Connect | работает, сквозной тест с Keycloak в CI |
| Регистрация машины и образ под неё | работает |
| Windows (Intune, PowerShell) | работает, в CI проверяется пробным запуском |

| Ключ машины в TPM, смарт-карты, NFC, мобильное приложение | в планах |
